# Yuyao Huang

Personal academic homepage at [exhyy.github.io](https://exhyy.github.io/), built with Jekyll.

## Editing

- `_config.yml`: profile and site metadata.
- `index.md`: biography, research interests, education, and experience.
- `_data/publications.yml`: publication entries.
- `_layouts/homepage.html` and `_includes/publications.md`: page markup.
- `assets/css/custom.css`: styles; `assets/js/navigation.js`: section navigation.

## Local preview

```sh
bundle install
bundle exec jekyll serve
```

Open `http://localhost:4000`. Use `bundle exec jekyll build` to generate `_site/`.
